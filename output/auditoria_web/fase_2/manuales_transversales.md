# Manuales transversales · Cumplimiento de la web

El registro conserva el carácter de cada regla. «Criterio demostrado» se limita al elemento y alcance identificados. «Evidencia pendiente» identifica el dato, documento o entorno que falta para completar la regla. Un ejemplo, preferencia o permiso del manual no se convierte en obligación. Las referencias de código parten de la raíz del proyecto. Las páginas son folios físicos.

Para el MC se contrastaron la interfaz y, como muestra de documentación técnica formal de la web, el MPW oficial, incluido el formato de sus páginas y la tabla 8. El informe anterior de 20/11 identifica otro commit. Sus conclusiones y pruebas no acreditan esta revisión. Para el MD se contrastaron la hoja maestra, cabeceras, ADR y el inventario versionado. El tablero, originales firmados y registros operativos externos no acompañan al corte. Cada fila indica qué puede acreditarse. Para recuperar el texto íntegro de cada control, usar su ID en el inventario de la Fase 1.
